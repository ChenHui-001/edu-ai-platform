# docs/archive —— 过期文档

这里存放**只作为当时证据**保留的文档。它们记录的是某个版本的真实状态与复盘，
不自称"当前"，也不随代码更新。

> **不要在这里新增内容。** 新的评估/复盘请写进 `audit-reports/BACKLOG.md` 的对应行，
> 或作为新的日期化文件放在 `audit-reports/`（并同步更新 BACKLOG 的引用）。

## 为什么归档

归档前这些文件是"文档基线漂移"的主要来源：新人打开 `ARCHITECTURE_ASSESSMENT`
看到的是 2.2.19 的端点/表数（272/49），而实际早已是 288/52，于是拿文档当依据
做出的判断全错。现状统一由 [`../STATUS.md`](../STATUS.md) 提供。
