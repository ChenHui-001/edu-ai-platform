# 学习闭环与教学扩展

版本以根目录 `VERSION` 和 `docs/STATUS.md` 为准。

## 交付范围与入口

| 功能 | 入口 | 验收要点 |
|---|---|---|
| 1. 持久补弱计划 | 学生 → 知识诊断 → 生成补弱学习计划；学习中心 → 练 → 补弱学习计划 | 完成诊断后幂等建计划；讲解、专项练习、复测；复测达 80 分后按 1/3/7 天复习；刷新恢复测验；正式掌握度仅由真实作答更新 |
| 2. 班级知识图谱 | 教师 → 班级知识图谱 | 按任教班级/学科显示薄弱人数、已测/未测人数和错因；选节点发布真实试卷及专项作业，学生可以作答 |
| 3. 共享数学渲染 | 诊断、补弱计划、随机练习、考试、错题本 | 题干、选项、解析共用公式渲染；结构化数轴、分数、几何图；保留上游题目及选项中的被动 SVG 图形 |
| 4. 题库质量工作台 | 教师 → 题库质量 | 搜索和分页；缺项、重复题干、选项重复、明确答案/解析冲突；知识点题量缺口；有审核权限才可发布或修改公共题图形；AI 题结构错误阻断发布 |
| 5. 引用式分步答疑 | 随机练习结果、错题本 → 分步答疑；教师 → 答疑纠错 | 提示/步骤/参考答案；引用由服务端关联真实题目与知识资料；规则降级明确标识；教师核对结果优先展示；考试中相关题目禁止答疑 |
| 6. 上游同步管理 | 系统管理员 → 上游数据同步 | 分支/标签/SHA 解析为固定提交；预览增改删与质检；写入前备份；同步历史；从最近一次依次恢复 |

管理员具备教学管理入口，但补弱计划仅供学生自己的账号操作。任课教师不因未设置账号年级而丢失自己的班级学情和学生反馈。

## 数据与安全边界

- `edu_remediation_plan` 保存计划、测验快照和作答结果；`version` 乐观锁防止并发覆盖，测验重复提交不重复累计掌握度。计划内前置步骤先练习和复测，再进入后续知识点。
- 每份计划最多 200 次测验；题库不足时明确提示复用题目，不把背过答案等同于可靠的复测证据。
- 到期复习提醒复用已有 `push_review_reminders` 定时任务，尊重学生通知偏好，同一复习轮次去重。应保持应用调度器及对应任务启用。
- 学生只获得题目展示字段，不获得 `accept`、`verify`、原始扩展 JSON 等判分信息；答案和解析仅在允许的结果页或提交后展示。
- KaTeX 禁用 trust、限制展开；上游 SVG 只保留被动绘图元素和属性，移除脚本、事件、foreignObject、外部链接及引用。结构化图形在前后端均校验坐标、数量和数值范围。
- 质量检查是确定性结构/显式冲突检查，不是数学语义正确性的自动证明，发布前仍需教师核对。
- 答疑引用表示“使用了这些题目和知识资料”，并非外部网页检索验证；未配置可用模型时使用资料规则降级，不能冒充模型结果。考试中不提供答疑入口，服务端也拒绝相关试题。
- 同步仅操作 `cn-math-taxonomy` 来源的数学知识点、题目、先修关系及题目知识点关联。业务账号、成绩、掌握度和其他学科不覆盖。恢复保留题目使用计数，新增对象归档而非硬删除，以保留业务关联。
- 同步备份为 **taxonomy 数据集 JSON 快照，不是整库备份**。源文件及预览后本地数据变化会触发 409，必须重新预览。SQLite 写锁串行化同步；非 SQLite 使用行锁。
- 上游许可为 **CC BY-NC 4.0**，来源为 [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy)。商业使用须另行授权。
- 既有运维自动同步脚本继续可用；页面记录的是页面发起的同步。完整本地/生产数据集一致性仍由既有双端同步及指纹检查保证，不把独立的业务数据库宣传成整库相同。

## 功能测试

```powershell
python tools/verify_learning_extensions.py
python tools/verify_knowledge_graph.py
python tools/verify_math_taxonomy_integration.py --source-dir ../.cache/cn-math-taxonomy
python tools/check_alembic_sync.py
python tools/check_new_code_tests.py
npm --prefix frontend run lint
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run check:bundle
```

新功能回归使用临时数据库和模拟固定上游目录，涵盖成功流程、失败状态、角色/班级/学科越权、乐观锁、重复提交、复习提醒去重、图形边界、质检阻断、考试保护、同步漂移及恢复。不会修改生产库或真实账号。

前端依赖需要 Node 22.12 以上；CI 使用 Node 22。视觉与业务验收建议按表中六个入口依次执行，不只检查菜单是否存在。
