# 1.6.0 年级管理检查与优化

## 一、发现的问题

1. **排序字段错位**：模型/后端字段是 `sort`，前端表格与表单用 `sort_order` → 排序列永远空白、保存的排序值被忽略（年级、学科都受影响）。
2. **新增年级默认值错误**：后端缺省 `grade_num=9`，新增「一年级」会得到序号 9；缺少名称/学段/序号校验与重名校验。
3. **编辑年级缺少校验**：可改成已存在的名称、任意/重复的序号、非法学段；没有防重复。
4. **删除年级漏查用户**：只检查班级/学科/知识点/题目/试卷/作业，仍有教师/学生挂在年级上时可能被删。
5. **权限过宽**：
   - 年级写接口使用 `get_current_manager`，**年级管理员可新增/编辑/删除年级**；
   - 学科写接口未限制年级管理员只能操作本年级；
   - 前端没有权限判断，所有能进页面的人都看到「新增/编辑/删除」按钮。
6. **UI 信息不足**：年级页只有名称/排序/说明/状态，缺学段、序号、班级数、学科数、学生数；无学段筛选与统计；新增弹窗没有学段/序号字段。

## 二、修复与优化

### 后端
- 新增权限点：
  - `resource:grade:write`（仅 sys_admin，`*` 覆盖）；
  - `resource:subject:write`（grade_admin 可维护本年级学科）。
- 年级写接口改为 `require_perm("resource:grade:write")`：年级管理员/教师/学生均 403。
- 年级校验：
  - 名称必填≤32、同名校验；
  - 学段仅 `primary/junior`；
  - 年级序号 1-999（兼容 E2E 合成年级 99/100）、唯一校验；
  - 编辑同样校验名称/序号/学段，默认状态/排序。
- 年级删除追加「用户」引用检查。
- 年级列表补充 `class_count/subject_count/student_count/stage_label`，支持 `keyword`；按 `grade_num` 排序。
- 学科写接口改为 `require_perm("resource:subject:write")` + scope：sys_admin 全量、grade_admin 仅本年级；创建/编辑/删除/跨年级复制均校验；`sort_order` 兼容 `sort`。
- 学科创建/编辑补名称、重名、年级存在性校验。

### 前端（ResourceManage.vue）
- 年级页新增统计卡：年级总数/小学/初中/启用年级。
- 年级表格新增：学段 tag、年级序号、排序、班级数、学科数、学生数；修复排序列。
- 筛选新增「学段」；新增/编辑弹窗新增学段、年级序号字段（小学/初中），排序字段修正为 `sort`。
- 权限：
  - 新增/编辑/删除按钮按 `resource:grade:write` / `resource:subject:write` 控制；
  - 年级页年级管理员只读；
  - 学科页年级管理员仅本年级行可编辑/删除，其他行显示「只读」；
  - 跨年级复制仅 sys_admin。
- 学科按年级视图排序列改为 `sort`，复制/编辑/删除按钮按行权限显示。

## 三、验证

- E2E：851 项 / 通过 837 / 失败 0 / 跳过 14（含年级 CRUD、教师/学生越权拒绝）。

## 四、名称规则（1.6.1 追加）

### 年级
- 新增/编辑不再手填名称：选择「学段」+「年级序号」后自动生成标准名（一年级…九年级）；
- 小学仅 1-6、初中仅 7-9，学段与序号不匹配会被后端拒绝；
- 后端 `auto_name=true` 时忽略客户端名称，按学段+序号强制生成；同名校验、序号唯一校验保留。

### 班级
- 默认自动命名：`{年级名称}({班级序号})班`，如 `七年级(3)班`；
- 只填「班级序号」（1-99），不再手输完整名称；新建时自动建议下一个可用序号；
- 特殊班级（如兴趣班）可开启「自定义名称」：
  - 长度 2-32；
  - 仅允许中文、字母、数字、中英文括号、间隔号、短横线、下划线、空格；
  - 后端 `strict_name=true` 同样校验，避免 `@@@`、符号堆叠等乱名；
- 同年级同名仍会被拒绝。

## 五、名称规则验证

- 班级自动命名：传 `class_no=9, name=乱七八糟@@@, auto_name=true` → 实际创建 `一年级(9)班`。
- 自定义非法名 `乱写@@@` → 400；自定义合法名 `一年级兴趣班` → 200。
- 年级自动命名：与现有年级重复 → 400「年级已存在」；学段/序号不匹配 → 400。
- 前端：年级弹窗名称为只读自动预览；班级弹窗显示自动名称/班级序号/自定义名称开关，无 console error。
